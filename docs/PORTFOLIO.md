# Bubble Sort：从玩法原型到关卡制作工具

[立即试玩](https://Norman0721.github.io/bubble-sort-puzzle/) · [打开编辑器](https://Norman0721.github.io/bubble-sort-puzzle/editor.html)

## 项目目标

制作一个可在浏览器直接体验的颜色消除游戏，并配套关卡工具，让布局、弹药与特殊球规则可以快速配置、验证和试玩。作品重点是玩法约束和制作流程的结合。

## 核心循环

观察棋盘与弹药 → 选择瞄准位置 → 松开发射 → 结算消除与特殊球变化 → 判断下一发策略。有限弹药让每次射击具有成本；隐藏球引入信息揭示，变色球让颜色关系随回合改变。

## 三个设计问题

### 1. 如何让关卡设计快速得到反馈？

编辑器复用游戏的坐标、颜色和容量规则，提供结构校验、容量检查与即时试玩。布局和弹药分开编辑，保存时仅更新各自负责的字段，降低相互覆盖的风险。

### 2. 如何支持复杂编辑而不让用户担心误操作？

增加批量选择、撤销重做、草稿恢复和离开提醒；非法移动、碰撞或越界会取消整个操作。弹药队列的批量修改作为一次历史操作记录。

### 3. 如何把桌面原型移到手机？

放大菜单点击区域、调整选关卡片、统一松手发射与取消行为，并考虑安全区和系统中断。仍需进一步进行真机触控和性能测试。

## 实现与验证

使用 HTML/CSS/JavaScript、Phaser 游戏基线、Python 单文件构建和 Node.js 自动测试。开发采用 AI 辅助实现与迭代；展示重点是可复查的规则、功能和产物，不把自动化测试视为真实玩家体验结论。
