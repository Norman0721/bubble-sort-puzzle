# 泡泡解谜 · 初始界面 V1.1

实现依据桌面《Bubble_Block_初始界面需求文档_V1.0》。基准画布为 672×1080，所有终端按 min(视口宽/672, 视口高/1080) 缩放并居中。横屏保留竖屏内容列并提示旋转，留边使用背景色延展。安全区 x=24…648、y=36…1044；按钮不裁切，手机、平板采用同一逻辑尺寸。

| 元素 | 位置与规格 | 字号与颜色 |
| --- | --- | --- |
| 标题 | 中心 (336,400)，480×160 透明切图，字形实际高度约44 | 等效44，白色 |
| 装饰泡泡 | 中心 y=465，直径32，中心间距44 | 红、蓝、绿、黄 |
| 主按钮 | (226,534)，220×52，圆角16，描边2 | 18，#DFF5E5；底 #2C5A3F，描边 #3D7A55 |
| 选择关卡 | (226,604)，220×52 | 18，#C6CBE8；底 #22253A，描边 #2A2E45 |
| 开发版编辑器 | (226,674)，220×52 | 同次级按钮 |
| 完美进度 | 中心 (336,755)，行高20 | 13，#8B93B8；全完美 #FFD54A |

按钮间净距18。主按钮与次级按钮分别提供两种材质，程序使用 CSS 绘制底板以保留清晰圆角；PNG 底板可用于后续美术替换。正常100%；精细指针悬停104%、150ms；按下98%、80ms，释放恢复60ms；禁用40%，移出Tab顺序；焦点为2px浅金描边。原生button支持Tab、Enter、Space，焦点顺序与垂直排布一致，整个矩形可点击。

标题循环周期3200ms，浮动0…-8px；泡泡周期1800ms，浮动0…-10px，相邻延迟130ms。进入淡入200ms。系统减少动态效果时停止循环。离开首页隐藏元素并拆除页面监听；Scene的pause/resume监听在shutdown清理，不创建首页粒子、音乐或持续游戏Tween。

状态稿位于 `design/01-first.png`、`02-continue.png`、`03-perfect.png`、`04-empty.png`，汇总为 `states.png`。`components.png`展示两类按钮的五种状态，`release.png`展示玩家版；玩家版不创建编辑器button、不包含工作室DOM与控制器。`adaptation.png`标注16:9、19.5:9、4:3的FIT与安全区。这些图是依据逻辑坐标生成的设计参考稿，不能代替实际浏览器截图。

资源源文件均为SVG；交付PNG在 `assets/`，背景1344×2160，LOGO960×320，8色装饰泡泡各256×256，底板720×192，星标与加载128×128。背景不含文字；透明资源均保持中心锚点。底板九宫格建议边界：[64,64,64,64]（2倍源图），保留角区，中间拉伸；程序目前使用CSS底板，无位图圆角拉伸。绘制脚本 `artwork.py`可重建向量稿。

内嵌首页PNG约0.54MB（Base64约0.72MB），主纹理解压约13.9MB；低于文档3MB/20MB建议值。数据无外部服务：bp_progress、bp_recent_level、bp_perfect从当前浏览器读取，非法数据回退首次进入；继续索引夹在有效范围，完美索引去重并剔除越界项。没有可用关卡时禁用开始/选关并允许重试。进度更新、跨窗口storage更新、返回首页均重新计算。全部完美进入最后一关。

构建：`python3 editor/build.py`输出开发版，保留用户所需编辑器；`python3 editor/build.py --release --output /tmp/Bubble-Block-Player.html`输出玩家版。当前桌面交付为开发版。

事件通过window的`bubble-analytics` CustomEvent统一发送，detail包含event/params，支持可选`window.BBAnalytics.track`。包含home_view、home_primary_click、home_level_select_click、home_editor_click、home_load_error，字段按需求文档命名；埋点失败不阻断跳转，不向外部发送数据。

验收：自动化涵盖AC01–AC13、AC16–AC20的状态、导航、错误恢复、适配、监听清理逻辑；AC14/AC15通过原生按钮结构与事件覆盖验证，尚需浏览器/触屏实机操作。资源尺寸与设计稿已检查。浏览器安全策略阻止打开本地HTML，本次未进行真实浏览器的画面、触控或性能验收；1秒可交互、60FPS与实机内存指标仍需目标设备测量。

按用户最新要求移除首页底部操作说明栏，程序与状态设计稿已同步更新。

V1.3按照用户明确的手机游戏定位调整触控布局。粗指针设备的三个入口使用352×104逻辑像素按钮，左边160，顶部508／636／764，字号32；完美进度移至884，字号26。原表格和状态稿保留精细指针布局，手机静态参考见 `../game/design/mobile-home.png`。首页与游戏画布共享扣除系统安全区后的FIT矩形，不再各自按完整视口计算缩放。详见 `../game/MOBILE.md`。
