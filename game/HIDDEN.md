# 隐藏球机制 V1.4

## 关卡数据

关卡继续使用字符串网格。小写颜色字符是普通球，大写颜色字符是拥有同色真实颜色的隐藏球。

| 配置 | 含义 |
| --- | --- |
| `r` | 普通红球 |
| `R` | 真实颜色为红的隐藏球 |
| `b` / `B` | 普通蓝球 / 隐藏蓝球 |
| `.` | 空格 |

八种现有颜色均支持这种表示。这一扩展不改变 `schemaVersion: 1`，旧关卡无需迁移。

## 运行时

- 开局加载后检查一次全部隐藏球。
- 每发的消除结算完成后，统一刷新全部隐藏球。
- 六方向直接相邻格中任一有效格为空时，将大写字符永久转为小写字符。
- 地图外的位置不当作空格；边缘隐藏球只检查地图内的有效相邻格。
- 所有待揭示对象先统一收集，再同时改变逻辑状态和视觉。
- 隐藏期间仍占据格子、参与碰撞，但不与小写颜色参与同色匹配。
- 揭示后只保留小写真实颜色，不会再次隐藏。

## 编辑器

在颜色面板下选择“普通球”或“隐藏球 ?”，再使用画笔或“应用当前颜色”。隐藏球在编辑器画布中显示 `?`，其外圈颜色和文字提示会显示真实颜色；游戏内的隐藏外观不泄露真实颜色。

## 刷新接口

`GameScene.refreshHiddenBubbles(animate)` 可在其他特殊清除或掉落机制完成整批棋盘修改后调用。当前射击结算已自动调用。
