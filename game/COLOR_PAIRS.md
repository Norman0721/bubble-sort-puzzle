# 变色球 · V1.6

关卡字段 `colorPairs` 保存配对成员，每个成员形如 `{ "id": "Pair_01", "c": 3, "r": 5 }`。坐标使用从 0 开始的绝对列、行。网格字符仍是球的当前实际颜色，因此原有匹配、消除、连接和滚动规则直接使用当前颜色。

在编辑器中放置两颗不同颜色的普通球，使用选择工具逐个点击两颗球，再点击“将所选球设为变色球”。也可拖动框选。Pair ID 留空时自动生成；也可以分别选中两颗球并输入相同 Pair ID。金色外圈和 ↔ 标识表示配对球。选中后可取消配对。配对设置、球移动、删除、换色均进入原有撤销历史。

每组必须恰好两颗球，且两颗初始颜色不同。单颗、超过两颗、重复位置、非法坐标或放在空格／隐藏球上的配置会阻止保存和试玩。

每次射击的匹配与移除结算完成后，仍同时存在的两颗球直接交换网格中的颜色。任一球从网格移除时，配对立即锁定，剩余球保留自己的当前颜色，之后作为普通球参与游戏。撤销射击恢复该发之前的网格颜色和配对状态。

V1.6 为机制初版，V1.7 增加逐个点选以便配置相距较远的配对球。现有版本文件保留。
