# 空白关卡版 · V1.8

`Bubble Sort Mobile V1.8.html` 保留 V1.7 的游戏、关卡编辑器、弹药队列、隐藏球、变色球和点选功能。构建时移除原有 50 个内置关卡数据。此版本只将自己编辑器中保存且配置了有效弹药的关卡加入游戏列表。

首次打开时首页显示“创建／编辑关卡”。进入编辑器后可点击“新建关卡”，设置 Level ID、名称和尺寸，绘制棋盘并保存，再配置弹药队列。完成后返回首页即可开始游戏或选关。

V1.8 使用独立的浏览器存储命名空间。旧版本的关卡、草稿和进度不会出现在此版本，也不会被删除；V1.8 中新建的关卡和进度会单独保存。若浏览器清理站点数据，新建关卡仍可能丢失，建议使用编辑器“导出”保存备份。

V1.9 延续这套空白关卡存储，因此 V1.8 中已创建的关卡会继续显示。V1.9 增加选中普通球后直接转为隐藏球及醒目的选中标记。

V1.10 同样沿用已有空白关卡数据，移除右侧关卡信息区的名称输入框；创建新关卡时仍可填写名称。

构建命令：`python3 editor/build.py --blank-levels --output 'Bubble Sort Mobile V1.8.html'`。
